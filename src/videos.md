# Videos

I've been recording these for a while now - screen recordings of me clicking through real tools and explaining what matters, mostly for people running small businesses who've been sold SEO nonsense over the years. They cover the same ground as my [written guides](/guides/) in places: keywords and how Google actually thinks about them, long-tail searches, targeting local areas, and step-by-step walkthroughs of free tools like Google Search Console and [SerpBear](/videos/tracking-search-results-serpbear/) for tracking your own rankings without paying an agency for the privilege. There's a fair bit of AI content in there too, both practical (automating tedious jobs, using code assistants with guardrails) and sceptical, because I have opinions about that.

Some of the videos cover tools I've built myself - [PATLog](/videos/patlog-pat-testing/) is a completely free PAT testing logger, built because the existing software costs daft money for what it does - and some are just answers to questions clients ask me regularly, recorded once so I can stop repeating myself. If you want to know whether any of this advice actually works in practice, [client reviews and outcomes are here](/reviews/).

Fair warning on production values: this is a Mancunian and a screen recording, not a studio. There are far slicker explainer channels out there and I'd happily point you at them. What you get here is a working web developer who's been building sites since the mid-2000s showing you the actual clicks.
