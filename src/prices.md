## Managed hosting (static sites)

You can host up to 20 websites with me for **£40** per month, or **£20 if discounted**. This is a hands-off package - I take care of the technical side so you can focus on your business:

- **Your sites stay online** - I monitor uptime and fix problems
- **Your content is safe** - automatic backups stored in two separate locations
- **Quick changes included** - email me updates and I'll make them for you
- **Bugs get fixed** - if something breaks, I sort it out
- **Marketing support** - personal help implementing strategies from my [free guides](/guides/) and [videos](/videos/)

All hosting with me runs on [Bunny.net](/hosting/) - that page explains how I use it. If you'd rather host elsewhere, you own the full source code; I recommend Bunny direct, [Netlify](https://netlify.com), [Pico.sh](https://pico.sh/pgs), or [Surge](https://surge.sh), and I'll help you set up wherever you like.

## Basic hosting (unmanaged sites)

If you update your site rarely, or prefer to handle changes yourself, this lighter package is **£10** per site per month, or **£5** per month if discounted:

- **Your site stays online** - hosted and backed up
- **Bugs get fixed** - if something breaks, I sort it out

You won't get personal marketing support or free content changes - but you can edit your site yourself, use my [free marketing guides](/guides/) and [videos](/videos/), or pay me or my brother Kevin at [KevinBurkeServices.com](https://kevinburkeservices.com) for content changes as needed.

If you'd rather not pay me anything, you own the code - host it yourself for free on [Cloudflare Pages](https://pages.cloudflare.com/), [Netlify](https://netlify.com), or [GitHub Pages](https://pages.github.com/), and I'll help you get set up.

## Managed hosting (web applications)

For custom web applications (booking systems, databases, business tools), I host your app on its own virtual server. Server costs start at around £5 per month, and I charge **£60** per month (or **£30 if discounted**) on top of that. You get full access to the server and its configuration. This includes:

- **Your app stays online** - I monitor uptime and fix problems
- **Your code is safe** - automatic backups stored in two locations
- **Your database is backed up daily** - and emailed to you for extra safety
- **Quick changes included** - I make small updates at your request
- **Marketing support** - personal help implementing strategies from my [free guides](/guides/) and [videos](/videos/)

You can also host the application yourself, since you own the full source code. I'm happy to help you get set up on any host.

## Chobble Tickets websites

If you want a simple website and would rather not pay a build fee up front, I can set you up on [Chobble Tickets](https://tickets.chobble.com), the ticketing platform I make, and run it as your website. This is a different arrangement from the hosting packages above: the site runs on Chobble Tickets, and the monthly fee covers the setup and support as well as the hosting.

It costs **£40 per month with no setup fee**, or **£20 per month** for charities, community groups and co-operatives. That includes:

- A hosted Chobble Tickets site on your own domain
- Your domain and email set up for you (you pay the registrar and email provider directly)
- Your listings, prices and business details imported from a brain dump in the chat thread, using the importers I've built for the platform
- Advice on running the site properly, with a standing chat thread for questions
- Signal or WhatsApp if that's easier for you
- Priority for feature requests

The site has a public listings page, news and content pages, and the booking and payment features. Ticket money goes straight to your own Stripe, Square or SumUp account, and Chobble takes no cut of sales.

It's built around listings and bookings, so it suits classes, sessions, appointments, hires, workshop places and events. It's limited in some ways and easier in others: it won't give you a completely bespoke page design, but it will get you online quickly without a build fee. [Chalkie's School for Dogs](https://www.chalkiesdogs.co.uk) is a good example of the arrangement in practice.

Managed Chobble Tickets hosting on its own is £50 a year or £5 a month, with 50% off the annual price for charities, community groups, artists and musicians. The £40 package is the one where I do the setup and stay on hand, and [the support page on the tickets site](https://tickets.chobble.com/support/) has the full detail.
